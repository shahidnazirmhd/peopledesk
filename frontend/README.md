# PeopleDesk frontend

React 19 + Vite + TypeScript, TanStack Router / Query / Table, Socket.IO client, Axios, Tailwind CSS, React Hook Form + Zod. The full guide is in the [root README](../README.md).

```bash
npm install
npm run dev          # http://localhost:5173  (needs the backend on :8000)
npm run build        # type-check + production build into dist/
npm run typecheck
npm test             # unit tests for the real-time cache logic
```

Configuration is optional (`.env.example`): `VITE_API_URL`, `VITE_SOCKET_URL`, `VITE_SOCKET_TRANSPORTS`.

Testing aid: open the app with `?transports=polling` to force Socket.IO long-polling for that tab, `?transports=websocket` for WebSocket only, `?transports=reset` to return to the default (polling → WebSocket upgrade).

Where things live: `src/routes` (file-based routes; `_authed.tsx` is the auth guard + layout), `src/hooks/useSocket.tsx` (one connection per session, events → query cache, room subscriptions), `src/lib/realtimeCache.ts` (idempotent cache updates), `src/lib/api.ts` (Axios + 401 handling), `src/lib/auth.ts` (token, expiry timer).

`src/routeTree.gen.ts` is generated by the router plugin on `npm run dev` / `build`.
